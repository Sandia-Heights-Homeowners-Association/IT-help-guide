Administration and hosting

Microsoft 365 owns mail, calendars, groups and SharePoint. The toolbox uses those services rather than creating a second calendar or membership directory. The toolbox and dashboard run on Azure App Service; the wiki uses an Azure container with MySQL and persistent file storage; the map uses GitHub Pages. See IT Infrastructure and Handover for repository ownership, deployment boundaries and the GRIT hosting transition.

For approved individual access to the SHHA GitHub organization or service administration, contact IT Help or office staff. Detailed access inventories, credentials and recovery procedures belong in approved private documentation.

For Neon, Name.com, Cloudflare, Resend, Google and the other hosting and production providers, start with the service account directory and sign-in guidance. Use SHHA's designated Google account where supported and linked; retain the documented Microsoft identities. Keep verified ownership, billing and recovery details in the approved private handover register.
